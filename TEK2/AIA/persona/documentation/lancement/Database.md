# Configuration de la Base de Données

Pour que le système d'authentification et de gestion des utilisateurs fonctionne correctement, n8n a besoin d'initialiser sa table interne.

---

### Procédure d'importation du schéma `users`

Depuis l'interface principale de n8n, vous pouvez trouver une section data tables:

* cliquez sur cette section
* cliquez sur `Create data table` au centre 
* Sélectionnez l'option `Import CSV`
* cliquez au centre pour ouvrir votre gestionnaire de fichier
* vous pouvez ensuite aller chercher le fichier `users.csv` situé dans le dossier `/database` du projet
* Cliquez deux fois sur `Create` pour confirmer l'importation

---

> **Note :** Une fois l'importation réussie, la structure est immédiatement opérationnelle. Vous pouvez retourner au menu principal en cliquant à nouveau sur l'onglet **Personal**.
