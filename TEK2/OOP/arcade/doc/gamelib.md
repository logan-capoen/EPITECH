## Add your game to the project

Here you will find all the documentation needed to integrate your game into the project.

### Game implementation

Your game must strictly implement the following interface:

[IGame](./game/IGame.md)

This interface defines the structure and methods that your game must follow.

---

### Asset management

You must also manage assets (images, sounds, etc.) by following these instructions:

[Assets](./game/Assets.md)

### Summary

- Implement the `IGame` interface  
- Follow the required structure  
- Properly manage assets
